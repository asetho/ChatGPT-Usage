Before you install

You’ll need a working Codex CLI signed into ChatGPT under your user account. Mac can also use the CLI bundled with the ChatGPT desktop app. Windows setup can offer to install the CLI.

Current releases are unsigned, and the Mac app is not notarized. Windows Smart App Control can block the app. Read the installation notice and keep system-wide security protections enabled.

Installation and security notes ↗

Independent. Open source.

ChatGPT Usage is an unofficial companion maintained by Aaron Whippo. It is not affiliated with or endorsed by OpenAI. The app uses your local Codex CLI; it has no app-owned telemetry service.
